Feature 1-Address Format 2-Address Format 3-Address Format

Syntax Example ADD A ADD A, B ADD A, B, C
Internal Meaning AC ← AC + M[A] R1 ← R1 + R2 or M[A] ← M[A] + M[B] R1 ← R2 + R3 or M[A] ← M[B] + M[C]
Register Reliance Implicit Accumulator (AC) register General purpose registers / Memory General purpose registers
Instruction Length Shortest instruction word size Moderate instruction word length Longest instruction word size
Program Size (Lines) More instructions required for complex arithmetic Moderate number of instructions Fewest instructions needed in program
Key Advantages Minimal bit overhead per instruction word; simple hardware decoding. Good balance between program length and instruction bit width. Preserves source operands; high execution throughput; clean math translation.
Key Disadvantages Requires extensive accumulator data movement; higher instruction count. Overwrites original contents of destination register or memory location. Requires large opcode/address bit fields; more complex decoding hardware.
